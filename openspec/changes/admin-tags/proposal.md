# Propuesta: Administración de Tags en Configuraciones

## Resumen
Agregar **Tags** en Configuraciones con UI estilo SevenRooms: categorías + pastillas de color.

## Motivación
Los tags ya existían en `tm_tags` y se usaban en hostess, sin UI admin. La referencia SevenRooms organiza tags por categoría con pastillas y botón +.

## Alcance
- Menú Configuraciones → Tags
- Categorías (`tm_tag_categorias`) con alcance Global/Local y flags Show on reservation / Show on chit
- Tags con color, vinculados a categoría
- UI: pastillas por categoría + botón + / editar al clic

## Fuera de alcance
- Tags por sucursal
- Hard delete
- Rediseño del selector hostess
